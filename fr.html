A11y Express

Un bookmarklet gratuit qui vérifie en un clic, dans la page ouverte, huit points de WCAG 2.2 : attribut lang, images sans alt, présence d'un h1 et sauts de niveaux, liens et boutons sans nom accessible, champs sans étiquette, identifiants dupliqués, cibles interactives de moins de 24 × 24 px (critère 2.5.8), lien d'évitement ou région main. Les messages du panneau sont en anglais.

Aucune donnée n'est envoyée : tout s'exécute dans votre navigateur. Le résultat s'affiche dans un panneau et peut être copié en JSON pour vos tickets.

Installer

Glissez ce bouton dans votre barre de favoris, puis cliquez dessus sur n'importe quelle page :

A11y Express

Ou copiez le code du bookmarklet : bookmarklet.txt · code source lisible : bookmarklet.js · dépôt GitHub (MIT).

Essayer sur une page synthétique

Ouvrez la page de test synthétique (contenu fictif avec défauts volontaires), puis cliquez sur le bookmarklet : neuf constats attendus, listés sur la page.

Retours et support

Retour volontaire via GitHub : ouvrir une issue. Voir SUPPORT.md (meilleur effort, sans délai garanti).

Ne transmettez aucune donnée privée. Les issues sont publiques : pas d'URL non publique, de données d'utilisateurs, de cookies, de jetons ni de captures contenant des informations personnelles. Reproduisez avec un exemple synthétique.

Limites

  • Vérifications automatiques partielles : elles ne remplacent pas un audit WCAG complet (contraste, clavier, lecteurs d'écran, contenu dynamique).
  • Le critère 2.5.8 admet des exceptions (cibles en ligne, espacement) : vérifiez manuellement.
  • Référence : WCAG 2.2, W3C, 12 décembre 2024.
