# Support

Support and feedback happen in public on GitHub Issues, best effort, with no guaranteed response time. There is no email, chat or paid support.

- **Bug:** use the *Bug report* form. Say which browser, what you expected, what you saw, and include a **synthetic** reproduction
  (a small HTML snippet or the [synthetic test page](https://decarvalhoe.github.io/capital-ops-horizon-a11y-express/examples/synthetic-page.html)).
- **Feedback or idea:** use the *Feedback* form. Telling us whether you actually used the tool on a real page (without naming it if it is not public) helps most.

## Do not send private data

Issues are public and permanent. Do not paste: non-public URLs, personal data, cookies, tokens or credentials, screenshots showing user information,
or the JSON output from a page that is not public. Anonymise or rebuild the case with fictional content first. Anything private posted by mistake
should be deleted by its author; we will ask for it to be removed.
